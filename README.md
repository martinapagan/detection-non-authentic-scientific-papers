# Detection of Non-Authentic Scientific Papers

This project focuses on developing machine learning and deep learning models for the identification and classification of inauthentic or artificially generated scientific articles, with a particular focus on the **SCIgen** case and more advanced generation methods.

This project was developed for the *Artificial Intelligence* course as part of the Master’s degree program in *Analytics and Data Science for Economics and Management* (Academic Year 2024/2025).

## Project Structure
The repository contains the entire workflow, from data collection to model deployment:

* **`ProjectAI_part1.ipynb` & `ProjectAI_part2.ipynb`**: Jupyter notebooks containing the Python code for web scraping (arXiv), text preprocessing, feature extraction via TF-IDF, and training of classification models.
* **`AI_report_Bertolotti_Paci_Pagan.pdf`**: The detailed academic report covering the methodology, pattern analysis (N-grams), and an in-depth discussion of the results.
* **`AI project.pdf`**: The project presentation slides.


## Technologies and Methodologies Used
* **Language:** Python
* **Main libraries:** Scikit-learn, Natural Language Toolkit (NLTK), BeautifulSoup (for web scraping), Pandas, NumPy, Matplotlib/Seaborn (for data visualization).
* **Text Mining & NLP:** Text preprocessing (tokenization, stop-word removal, lemmatization), TF-IDF vectorization, N-grams, pattern recognition.
* **Classification Models:** Comparison of various classifiers (e.g., SVM, Random Forest, Logistic Regression) evaluated using accuracy metrics and ROC curves (AUC).

## Summary of Results
The project demonstrates the effectiveness of NLP techniques in identifying the syntactic and grammatical structures typical of texts generated by algorithms such as SCIgen, as compared to authentic articles extracted from the arXiv database (Computer Science section), highlighting the importance of studying N-grams for linguistic pattern recognition.
